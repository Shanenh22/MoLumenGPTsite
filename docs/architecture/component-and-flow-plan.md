# Component, wireframe, and flow plan

## Core components

`SiteHeader`, `DesktopNav`, `MobileNavDialog`, `SiteFooter`, `SeoHead`, `Breadcrumbs`, `Button`, `TextLink`, `Card`, `ServiceCard`, `ServiceComparison`, `PolicyNotice`, `NewsletterForm`, `VideoFacade`, `BookingPanel`, `ReadingFinder`, `ChartExplorer`, `SkyTimeline`, `FilterGroup`, `Disclosure`, `StatusMessage`, and `ErrorSummary`.

## Page-family wireframes

- **Home:** compact header → brand/real portrait hero → recognition → Reading Finder → verified readings → Mo preview → process → approved proof → chart explorer → Current Sky → learning/video → newsletter → calm CTA → footer.
- **Readings:** orientation → comparison cards → selector → process/requirements → FAQ → booking CTA.
- **Service:** purpose → price/duration/format summary → best for/not for → session and deliverables → birth data/preparation → policies → FAQ → booking.
- **Learn/article:** answer-first introduction → contextual navigation → main explanation → Mo’s viewpoint label → related terms/content → next step.
- **Booking:** selected service summary → requirements/privacy → Cal.com embed on user action → hosted fallback → policies and support.

## Reading Finder flow

Start → broad understanding vs current situation → area of focus → defined question → birth-time availability → recommend only an approved service → explain fit/alternative → details or booking. Answers live only in component memory and disappear on refresh/exit.

## Explore Your Chart flow

Static accessible wheel plus equivalent grouped controls: Planets (functions) → Signs (style) → Houses (area) → Aspects (relationship). No birth-data input and no personalized calculation.

## Current Sky flow

Upcoming/recent timeline from a reviewed data file → filter by event type → clearly label factual timing vs Mo’s interpretation → deep link to a real article → automatically hide outside display window and provide archival instructions.

## Booking flow

Verified service → review price/duration/format/data → open Cal.com → time zone → intake and terms → Stripe payment → confirmation/reminders/calendar → preparation. Completion analytics fire only from a reliable Cal.com completion signal or confirmed return page.

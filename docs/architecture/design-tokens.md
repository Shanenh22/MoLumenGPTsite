# Design-token direction

Tokens will live in one CSS layer with semantic aliases; values below are starting points requiring moodboard and contrast review.

| Role        | Draft token                                     |
| ----------- | ----------------------------------------------- |
| Canvas      | warm ivory `#F7F1E7`                            |
| Surface     | parchment `#EDE2D1`                             |
| Text        | deep navy `#17243A`                             |
| Muted text  | natural brown `#62574D`                         |
| Accent      | muted blue `#58718B`                            |
| Highlight   | antique gold `#A98547`                          |
| Warm accent | clay `#A8644F`                                  |
| Border      | soft stone `#CFC4B7`                            |
| Focus       | high-contrast blue/gold pair, tested in context |

Use a licensed editorial serif for headings and highly legible sans serif for interface/body. Start with a fluid type scale, 4/8-based spacing, content widths around 42–72rem by page family, restrained 1px borders, small radii, subtle shadows, and motion under 200ms with a no-motion alternative. Avoid decorative icons where text is clearer.
